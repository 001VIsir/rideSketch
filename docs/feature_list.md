# 功能列表

## 用户模块

### F001 - 用户注册
- **描述**: 用户可以通过用户名和密码注册账号
- **步骤**:
  1. 访问注册页面
  2. 填写用户名、邮箱、密码
  3. 点击注册按钮
  4. 系统验证信息并创建用户
- **状态**: 已通过
- **优先级**: 高

### F002 - 用户登录
- **描述**: 用户可以登录系统，获取JWT Token
- **步骤**:
  1. 访问登录页面
  2. 输入用户名/邮箱和密码
  3. 点击登录按钮
  4. 系统验证并返回Token
- **状态**: 已通过
- **优先级**: 高

### F003 - 用户信息管理
- **描述**: 用户可以查看和修改个人信息
- **步骤**:
  1. 进入个人中心
  2. 查看/修改头像、昵称等信息
  3. 保存修改
- **状态**: 未通过
- **优先级**: 中

## 地图模块

### F101 - 地图展示
- **描述**: 在前端页面展示高德地图

  1. 打开应用
  2. 地图自动加载并展示

## 路线规划模块-利用项目里的高德API文档


### F201 - 基础路径规划
- **描述**: 使用高德API进行基础骑行/步行路线规划
- **步骤**:
  1. 设置起点和终点
  2. 选择出行方式（骑行/步行）
  3. 系统计算并显示路线
- **状态**: 已通过
- **优先级**: 高

### F202 - AI智能路线规划
- **描述**: 用户输入自然语言描述，LLM分析并规划路线
- **步骤**:
  1. 用户输入如"我想从北京邮电大学骑自行车出发，全程30公里，以看景点为主，请你给我推荐路线"
  2. 后端调用LLM分析意图
  3. LLM调用高德API获取POI信息
  4. 生成推荐路线
  5. 前端显示路线
- **状态**: 已通过
- **优先级**: 高

### F203 - 多途经点路线
- **描述**: 支持添加多个途经点
- **步骤**:
  1. 设置起点和终点
  2. 添加途经点
  3. 系统计算最优路线
- **状态**: 已通过
- **优先级**: 中

## 图案路书模块


### F301 - 图案路书生成
- **描述**: AI Agent自动生成图案形状的骑行路线
- **步骤**:
  1. 用户输入如"我想在北京市内骑行出一个从俯视图看为'2026'的路线"
  2. AI Agent分析图案坐标点
  3. Agent调用高德API搜索沿途可通行道路
  4. 生成符合图案形状的路线
  5. 前端显示图案路线和量化数据
- **状态**: 已通过
- **优先级**: 高

### F302 - 路线量化数据展示
- **描述**: 显示路线总距离、预计时间、难度等数据
- **步骤**:
  1. 生成路线后
  2. 系统计算并展示量化指标
- **状态**: 已通过
- **优先级**: 中
