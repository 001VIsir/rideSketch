# 项目经历 - rideSketch 智能骑行路线规划平台

## 项目概述

**项目名称**: rideSketch (骑迹) - 智能骑行路线规划与社区分享平台
**项目类型**: 全栈式前后端分离应用
**技术栈**: Spring Boot 3.5 + Vue 3 + MySQL + Redis + Ollama + 高德地图
**开发周期**: 2026年2月

---

## STAR法则项目经历

### 1. 业务需求是什么 (Situation)

随着骑行运动的普及，用户需要一个集路线规划、知识问答、社区分享于一体的综合平台。具体需求包括：

- **地图交互**: 在地图上展示、搜索地址、拾取坐标
- **路线规划**: 骑行/步行路线规划，支持多途经点
- **AI智能规划**: 用户输入自然语言描述，AI分析意图并自动规划路线
- **图案路书**: 生成特定图案形状的骑行路线
- **社区分享**: 用户发布路线、浏览他人路线、点赞评论互动
- **知识问答**: 基于RAG的骑行知识智能问答系统

### 3. 怎么解决的 (Action)

#### 3.1 技术架构设计
- 采用Spring Boot 3.5 + Java 17作为后端框架
- 使用Spring Security + JWT实现无状态认证
- 集成MyBatis-Plus简化数据库操作
- 使用Redis缓存提升性能

#### 3.2 地图与路线规划
- 集成高德地图Web API，提供搜索、编码、路径规划服务
- 设计RouteService统一处理骑行/步行多模式路线规划
- 实现AIRouteService利用Ollama(qwen3:8b)理解用户自然语言输入
- 使用PatternRouteService生成图案形状的骑行路线点阵

#### 3.3 AI智能实现
- 升级到Spring AI框架，重构AI服务架构
- 设计Prompt模板引导大模型理解骑行路线规划场景
- 实现Function Calling能力，让AI能调用高德地图API

#### 3.4 RAG向量检索（重点突破）
- 下载nomic-embed-text embedding模型
- 创建EmbeddingService直接调用Ollama向量API
- 设计KnowledgeBaseLoader实现知识库向量化存储
- 实现余弦相似度计算进行语义匹配
- 扩展知识库至97条知识，涵盖9个类别

```java
// 向量相似度计算
public float cosineSimilarity(float[] vec1, float[] vec2) {
    float dotProduct = 0, norm1 = 0, norm2 = 0;
    for (int i = 0; i < vec1.length; i++) {
        dotProduct += vec1[i] * vec2[i];
        norm1 += vec1[i] * vec1[i];
        norm2 += vec2[i] * vec2[i];
    }
    return dotProduct / (float)(Math.sqrt(norm1) * Math.sqrt(norm2));
}
```

#### 3.5 前端集成
- 使用Vue 3 + TypeScript + Vite构建前端
- 集成Element Plus UI组件库
- 使用Pinia进行状态管理
- 封装高德地图组件，实现地图交互功能

## 核心亮点

### 亮点一：AI + 地图深度融合
- **创新**: 将大语言模型与地图服务结合，用户用自然语言描述需求即可获得规划路线
- **价值**: 降低使用门槛，提升用户体验

### 亮点二：RAG向量语义检索
- **创新**: 使用Ollama embedding模型实现真正的语义搜索，而非简单关键词匹配
- **价值**: 知识问答更智能，支持近义词理解

### 亮点三：图案路书创意功能
- **创新**: 将图案转化为地理坐标点，生成可骑行的创意路线
- **价值**: 增加产品趣味性，满足社交分享需求

### 亮点四：完整社区生态
- **创新**: 从路线发布到社交互动，形成完整闭环
- **价值**: 增强用户粘性，构建骑行爱好者社区
